Control your Roku TVs and Roku Streaming Players locally via Roku's official External Control Protocol (ECP).

Features:
- Native Homey TV Remote Widget support (power, volume, mute, channel, and media playback controls).
- Automatic differentiation between Roku TVs and Roku Streaming Sticks (automatically hides TV-only volume and channel controls on streaming sticks).
- Displays the currently running Roku channel or app (e.g., Netflix, YouTube, Plex).
- Automatic local network discovery via SSDP with manual IP address fallback.
- Flow cards for launching installed channels, checking if a specific channel is running, triggering when the active app changes, sending any ECP remote key, and switching HDMI inputs on Roku TVs.

Note for Roku OS 11.5+:
Ensure mobile app control is enabled on your Roku device under Settings → System → Advanced system settings → Control by mobile apps → Permissive.
